# GitKeyRouter v0.4.18 开发记录

## 目标

让 GitHub CLI 身份选择过程可解释、可复现，并修正复杂 Git remote 场景下的目标选择。

## 已完成范围

- 新增只读 `gh-resolve` 命令及 `--json` 输出，不创建凭据目录、不调用 GitHub API。
- 报告 GitHub CLI 路径、发现来源、版本和候选，以及仓库、remote、push URL、HostAlias、身份、`GH_HOST` 和 `GH_REPO`。
- remote 优先级采用分支 `pushRemote`、`remote.pushDefault`、跟踪 remote、`origin`。
- 校验选中 remote 的全部 push URL 必须指向同一身份和仓库；未选中 remote 只报告警告。
- HTTPS remote 只在仓库路由唯一时回退，SSH HostAlias 与路由不一致时继续失败关闭。
- 修复 HTTPS URL 被 SCP-like 解析器误判为 SSH remote 的问题。
