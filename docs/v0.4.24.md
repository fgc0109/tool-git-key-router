# GitKeyRouter v0.4.24 开发记录

## 目标

在 v0.4.23 安全更新能力上补齐系统托盘驻留，并让更新检查、安装和退出流程与托盘生命周期保持一致。

## 已完成范围

- 默认在关闭或最小化主窗口后驻留系统托盘，并提供可持久化开关。
- 托盘支持双击恢复窗口，右键菜单提供打开、检查更新和退出。
- 第二次启动 GUI 时唤醒已有实例；Windows 关机、显式退出和安装更新时仍会真正退出。
- 更新提示使用独立窗口，区分下载并安装、查看 Release 和稍后提醒。
- MSI 安装版继续使用 SHA-256 校验与独立更新器；便携版保持不自覆盖边界。
