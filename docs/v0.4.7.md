# GitKeyRouter v0.4.7 开发记录

## 版本目标

统一配置加载、备份和恢复对 `SchemaVersion` 的解析，防止属性名大小写差异触发错误的旧版迁移并丢失当前字段。

## 实现范围

- 新增单一 schema 读取器，按 `OrdinalIgnoreCase` 查找版本属性。
- 属性缺失时继续兼容 Schema 1；JSON 根节点不是对象时拒绝读取。
- 重复版本属性、非整数版本、低于 1 或高于当前支持版本时明确失败。
- 应用配置加载、备份清单记录和恢复兼容性校验共用相同解析语义。

## 测试与失败语义

- 使用小写 `schemaVersion` 加载完整 Schema 4 配置，验证服务、端口、身份、路由和 Profile 均保留。
- 使用小写的未来 schema，验证加载与备份恢复都拒绝且当前配置不变。
- 使用小写版本创建快照，验证 manifest 记录正确的应用配置 schema。
- 继续覆盖 Schema 1、2、3 的迁移回归。
