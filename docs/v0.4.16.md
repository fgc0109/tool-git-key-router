# GitKeyRouter v0.4.16 开发记录

## 目标

统一应用视觉，并提供可以在不同 Windows 电脑之间迁移完整 GitKeyRouter 设置与 SSH 密钥的加密便携备份。

## 已完成范围

- 为网站、窗口、任务栏和发布 EXE 提供统一的 Git 路由/钥匙主题图标。
- 新增口令加密的 `.gkrbackup` 导出与导入，覆盖应用配置、SSH Config、Git rewrite、Git Profiles 及身份引用的密钥文件。
- 使用 AES-GCM、包结构校验、版本检查和 SHA-256 完整性验证保护导入。
- 将导入密钥重新映射到目标电脑的 `.ssh\GitKeyRouter` 目录，并在任一步骤失败时回滚全部已修改状态。
- 修复 Release 元数据解析，确保多提交快进推送只读取发布提交自身变更的说明文件。

## 验收

- v0.4.16 Release 构建、测试、两种 Windows x64 单文件发布和资产校验通过。
- 正式标签 `v0.4.16` 与 GitHub Release 已生成。
