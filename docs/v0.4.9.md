# GitKeyRouter v0.4.9 开发记录

## 版本目标

收紧默认身份与服务级路由的所有权和清理生命周期，避免清除默认身份后残留仍然生效的服务回退路由。

## 实现范围

- 默认身份派生的路由统一使用 `service-default:<serviceId>` 作为托管标识。
- 旧配置已有未标记服务路由时，保存默认身份会将该路由纳入托管，而不是留下无法清理的手工 ID。
- 清除默认身份时删除托管服务路由，保留同服务的 Owner / Repository 路由。
- 诊断规则对所有 Git 服务统一检查默认身份与服务路由，不再把合法的 GitHub 默认回退误报为禁止配置。
- 中英文文档明确默认回退和更具体路由的优先关系。

## 测试与失败语义

- 验证旧服务路由被转换为托管 ID，随后清除默认身份会删除它。
- 验证 Owner 路由在设置和清除默认身份的全过程中保持不变。
- 验证 GitHub 默认身份与托管服务路由不产生诊断错误。
- 继续覆盖 GitHub 默认回退创建、自建服务保存删除和连接参数回归。
