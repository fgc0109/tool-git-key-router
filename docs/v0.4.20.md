# GitKeyRouter v0.4.20 开发记录

## 目标

在保持 `gh` 原生命令行交互和退出码不变的前提下，为独立 GitHub CLI 身份增加跨进程并发隔离，并消除继承 Git 环境导致的仓库或凭据串号。

## 已完成范围

- 每个身份目录使用操作系统文件共享语义实现共享/独占锁；已登记身份的普通命令可并发执行。
- 首次身份登记、`gh-login`、`gh-logout` 和会修改本地扩展目录的 `gh extension` 使用独占锁。
- 登录、登出和执行在取得锁后重新校验身份清单，避免等待期间配置被替换。
- 子进程除固定 `GH_CONFIG_DIR`、`GH_HOST` 和 `GH_REPO` 外，还清除 Token、Git 仓库路径、SSH/ASKPASS 和 Git 配置覆盖变量。
- 继续阻止包装执行 `gh auth`、`gh config`、`gh alias` 和自定义 `--hostname`；账号生命周期统一走专用命令。
- 服务层返回不含参数、输出和凭据的执行回执，只记录身份、HostAlias、账号、Host、仓库、`gh` 版本、退出码、耗时和锁模式。
