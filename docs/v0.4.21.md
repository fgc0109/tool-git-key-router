# GitKeyRouter v0.4.21 开发记录

## 目标

在保留现有单文件便携包的同时，增加适合普通 Windows 用户的标准 MSI 安装、升级、修复和卸载链路，并把安装包纳入同一套发布校验与 SHA-256 清单。

## 已完成范围

- 使用 WiX 构建两个 Windows x64 安装包：推荐的自包含 MSI 和轻量的依赖框架 MSI。
- 安装器采用独立多文件负载；便携 ZIP 继续保持单文件 EXE，两种交付互不改变。
- 默认按机器安装到 `C:\Program Files\GitKeyRouter\`，允许修改目录，创建开始菜单入口，并提供默认勾选、可取消的桌面快捷方式。
- 使用稳定 UpgradeCode 支持覆盖升级、修复和从 Windows“已安装的应用”卸载。
- MSI 记录安装类型和实际目录，不把用户配置、SSH 密钥或 GitHub CLI 凭据写入安装目录。
- 发布脚本和 GitHub Release 工作流一次生成两个 MSI、两个 ZIP 及覆盖全部四个资产的 `SHA256SUMS.txt`。
- 结构校验读取真实 MSI 数据库，核对版本、目录、快捷方式、注册信息、多文件负载和 .NET 运行时边界。
- 增加手动安装器生命周期工作流，可对两个变体执行安装、可选前序版本升级、已安装程序 `--version` 冒烟和卸载清理，并保留 MSI 日志。

## 安全与兼容边界

- 安装和卸载只管理程序文件、快捷方式及安装器标记，不删除 `%APPDATA%\GitKeyRouter`、SSH 密钥或 Git/GitHub CLI 配置。
- 自包含 MSI 内含 .NET 10 运行时；依赖框架 MSI 明确要求 .NET 10 Desktop Runtime x64。
- MSI 当前未做 Authenticode 签名；签名证书、CI 私钥托管与时间戳策略仍需单独确定。
