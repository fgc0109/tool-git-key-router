# GitKeyRouter v0.4.14 开发记录

## 版本目标

消除 ProcessRunner 测试对 Windows shell、网络工具和 100 ms 调度猜测的依赖，让超时、取消、输出和进程树验证可重复。

## 实现范围

- 新增无第三方依赖的 `GitKeyRouter.ProcessTestChild` 控制台测试工具。
- 固定模式分别生成 stdout/stderr、多字符单行、挂起进程和嵌套子进程树。
- 测试项目构建后把 helper apphost、runtimeconfig 和依赖复制到隔离输出目录。
- ready 文件使用临时文件后原子移动；测试观察到握手后才触发用户取消。
- 超时测试先证明 helper 已进入挂起状态，再等待明确超时。
- 子进程树测试读取真实子 PID，并验证 `Kill(entireProcessTree: true)` 后子进程退出。
- 移除 `cmd.exe`、`ping` 和 100 ms CancellationTokenSource/timeout。

## 测试与失败语义

- 7 项 ProcessRunner 测试覆盖双流头尾截断、超长单行、启动失败、超时、取消、进程树和终止诊断。
- ready 握手本身有 10 秒故障上限；它只用于报告 helper 未就绪，不参与取消/超时结果判定。
- 仍保留真实 Windows apphost 与进程树行为，而不是用纯 mock 替代系统边界。
