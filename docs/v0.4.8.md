# GitKeyRouter v0.4.8 开发记录

## 版本目标

修正 GUI 与 CLI 的单实例边界，让只读和发布验证命令在 GUI 运行时可用，同时继续阻止跨进程并发写入。

## 实现范围

- GUI 启动与确认写入的 `apply --yes`、`apply-profiles --yes` 使用同一排他锁。
- 预览、诊断、列表、URL 解析、路由解析和连接测试命令不占用排他锁。
- `version` / `--version` / `-v` 与 `help` / `--help` / `-h` 在应用服务创建前直接执行。
- 发布冒烟测试改用每次运行唯一的临时发布目录，不删除或覆盖用户正在运行的正式/开发产物。

## 测试与失败语义

- 覆盖所有无服务启动命令别名、只读/预览命令和确认写入命令的锁策略。
- 保留同名 mutex 只能有一个所有者的单实例回归。
- 发布验证继续检查两种 EXE、版本输出、体积、MZ 头、ZIP 和 SHA-256，但与工作区 `artifacts` 隔离。
- 只有 GUI 或确认写入命令遇到已占用排他锁时返回退出码 4。
