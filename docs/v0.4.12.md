# GitKeyRouter v0.4.12 开发记录

## 版本目标

让异常、残留或未来版本的备份目录可见、可解释，并提供受边界约束的预览式清理，而不是依赖手工删除。

## 实现范围

- 扫描备份根目录全部直接子项，分类为完整、pending、损坏、版本不支持或未知。
- 完整备份在列表阶段验证 manifest、所需文件、长度和 SHA-256。
- UI 展示状态、原因、文件完整性和是否允许清理；只有完整备份可查看或恢复。
- 清理先生成目标预览，确认后执行，并在删除前重新扫描状态和时间戳。
- 完整备份、重解析点、路径逃逸、活动 pending 和一小时保护期内的 pending 一律拒绝清理。
- 清理失败或预览后目标变化时保留目录并报告原因。

## 测试与失败语义

- 覆盖五种健康状态及完整备份 SHA-256 验证。
- 覆盖直接子目录限制、完整备份保护、根目录外路径和清理成功。
- 覆盖近期 pending、模拟重解析点、删除失败及预览后状态变化。
- 现有原子发布、恢复完整性和 Git rewrite 回滚测试继续通过。
