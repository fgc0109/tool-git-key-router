## 测试用例

### Git Profile 事务

- Git 与全局 `include.path` 无法读取时不修改正式文件。
- 所有生成文件先写入临时目录并通过 Git 语法验证。
- 写入、清理、include 注册或最终验证失败时恢复原文件和原 include 集合。
- 成功后重新读取正式文件集合与全局 Git 配置。

### 预览冲突检测

- SSH config 在预览后被修改或新建时拒绝覆盖。
- Git Profile 文件在预览后被修改、新建或删除时拒绝应用。
- 文件未变化时继续正常应用。

### Git URL Rewrite 回滚

- 部分添加失败时恢复所有受影响 key 的原始值。
- 应用失败与回滚失败分别返回可诊断错误。
- 成功后验证目标 key 的精确值集合，不触碰计划外配置。

### SSH 严格同步

- 保守同步更新和新增已配置身份，但保留孤儿 managed block。
- 严格同步删除不再对应身份的完整 GitKeyRouter managed block。
- 严格同步不删除注释、普通 `Host` 配置或不完整标记块。
- diff 明确展示删除内容，并继续使用预览版本冲突保护。

### 原子备份目录

- 快照先写入 `.pending-<guid>` 临时目录。
- 文件、SHA-256 和 manifest 完成并回读验证后才发布正式目录。
- 写入、校验、取消或发布失败时清理临时目录，不产生可见正式备份。
- `ListAsync` 忽略 `.pending-*`，并继续兼容现有备份。

### 子进程执行

- stdout 和 stderr 超过限制后分别设置截断标记，并保留头尾诊断。
- 单行输出长度受限。
- 启动失败、用户取消、超时和终止失败明确区分。
- 终止进程树后执行有限等待，并记录 `KillFailed` 与 `TerminationError`。
