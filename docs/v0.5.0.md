## 测试用例

### SSH 严格同步

- 保守同步更新和新增已配置身份，但保留孤儿 managed block。
- 严格同步删除不再对应身份的完整 GitKeyRouter managed block。
- 严格同步不删除注释、普通 `Host` 配置或不完整标记块。
- 严格同步 diff 明确展示删除内容，并继续使用预览版本冲突保护。

### 原子备份目录

- 快照先写入 `.pending-<guid>` 临时目录。
- 文件、SHA-256 和 manifest 完成后才发布正式目录。
- 写入、校验、取消或发布失败时不留下可见的正式备份。
- `ListAsync` 忽略 `.pending-*`，并继续兼容现有备份。

### 子进程执行

- stdout 和 stderr 超过限制后分别设置截断标记。
- 截断输出保留头部摘要和尾部诊断。
- 用户取消与超时状态明确区分。
- 启动失败保留 `StartException`。
- 进程树终止后执行有限等待；终止失败时记录 `KillFailed` 和错误信息。

### 完整验证

- Release 配置完整测试。
- Release 配置完整构建。
- 最终提交数量、顺序和路径审计。
