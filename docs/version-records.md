# GitKeyRouter 版本记录索引

本目录中的 `vX.Y.Z.md` 用于记录版本目标、开发范围、计划或实际提交、测试用例和开发状态。它与 `.github/releases/vX.Y.Z.md` 的用途不同：

- `docs/vX.Y.Z.md` 是开发与历史审计记录，可以补录。
- `.github/releases/vX.Y.Z.md` 是正式发布说明；修改该目录可能触发 Release 工作流，因此历史补录不修改其中的既有文件。
- 没有可靠证据的版本不会被补写成正式发布。

## 记录原则

1. 历史版本的“计划提交数量”和精确测试数量只有在现有资料能够证明时才填写；否则明确标记为未知。
2. 正式发布状态以发布说明、版本配置、标签和产物证据综合判断，不由文件名单独决定。
3. 新版本开发记录应在实现期间持续更新，并在正式发布前核对版本号、发布说明、测试、构建、产物和标签。
