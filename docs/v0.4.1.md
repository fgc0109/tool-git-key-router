# GitKeyRouter v0.4.1 开发记录（历史补录）

## 记录性质

本记录依据现有的 [v0.4.1 正式发布说明](../.github/releases/v0.4.1.md) 与可达提交历史补录。历史开发计划未完整保留。

## 版本目标

修复 Gitea 默认身份路由未实际写入 Git 全局配置的问题，并补齐旧路由迁移、SSH managed block 协调、URL 预览和本地双版本发布流程。

## 计划提交数量

历史资料不足，无法可靠确认。可达历史中存在与该版本相关的发布、测试和文档提交，但不能据此断言完整计划数量。

## 已确认范围

- 修复 Gitea 登录账号被错误当作仓库 Owner。
- 增加 Gitea 服务级默认身份并隔离不同实例。
- 允许独立 Gitea 实例共享同一 SSH 密钥。
- 修复 SSH managed block 字段协调和 URL 预览状态。
- 增加旧 Gitea Owner 路由的检测、预览和确认迁移。
- Git config 继续采用幂等协调，只重置受管 key。
- “应用服务配置”串联备份、SSH 同步、路由迁移、rewrite 写入、预览和诊断。
- 增加本地自包含与依赖框架发布脚本。

## 测试与验证

可达历史包含发布流程和 Windows 双版本可执行文件验证相关测试提交；正式发布说明列出了两个 ZIP 与 SHA-256 文件。历史精确测试总数和每项终态结果未保留。
