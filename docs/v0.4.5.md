# GitKeyRouter v0.4.5 开发记录

## 版本目标

修复 SSH 密钥重命名对非 GitHub 服务参数的破坏。重命名只改变密钥路径，不改变身份所属服务的主机、端口或 SSH 用户。

## 实现范围

- 预览和应用重命名时，按每个身份的 `ServiceInstanceId` 查找实际 Git 服务。
- 使用服务感知的 SSH managed block 更新接口，保留 Gitea、GitLab 和自建服务参数。
- 身份引用不存在的服务时，预览明确失败；应用期间服务发生变化时进入既有回滚流程。
- 同步更新中英文使用说明。

## 测试与失败语义

- 验证自建 Gitea 的 `HostName`、非默认端口和自定义 SSH 用户在预览及应用后保持不变。
- 验证缺失服务时不移动密钥、不创建快照、不修改配置。
- 保留共享密钥身份和目标冲突的原有回归测试。
