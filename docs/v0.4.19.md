# GitKeyRouter v0.4.19 开发记录

## 目标

为独立 GitHub CLI 目录增加可核验的身份生命周期，并在不读取 Token 值的前提下强化凭据健康检查。

## 已完成范围

- 账号反查成功后原子写入无敏感信息的 `identity.json`，记录稳定身份 ID、GitHub Host、HostAlias 和预期账号。
- 已有 v0.4.17 目录只有在真实账号核验成功后才登记；清单损坏或与当前身份不一致时失败关闭。
- `gh-status --all [--json]` 可检查全部配置的 GitHub 身份。
- 新增 `gh-logout <identity> --yes`，精确指定 Host 和 AccountName，不使用全局账号切换。
- `hosts.yml` 检查增加 1 MiB 上限、reparse point 拒绝，以及普通/引号形式 `oauth_token` 键识别。
- logout 成功后只删除非敏感身份清单，保留目录供诊断；不会自动删除或迁移凭据。
