# GitKeyRouter v0.4.4 开发记录（历史补录）

## 记录性质

本记录依据现有的 [v0.4.4 正式发布说明](../.github/releases/v0.4.4.md)、当前版本配置和可达提交历史补录。

## 版本目标

将应用、测试和发布链路统一升级到 .NET 10，处理 WinForms 兼容性要求并重新生成 Windows x64 发布包。

## 计划提交数量

历史计划数量未保留。可达历史中确认存在提交 `bcc2ac5c`（`release: upgrade GitKeyRouter to .NET 10 and v0.4.4`），但不能据此断言该版本只有一个开发提交。

## 已确认范围

- 应用、Core、Infrastructure 和测试项目升级到 `net10.0` / `net10.0-windows`。
- Windows x64 自包含和依赖框架发布改用 .NET 10。
- CI 与 Release 工作流使用 .NET 10 SDK。
- 处理 .NET 10 WinForms 设计器、编译器和页头布局兼容性。
- 版本号从内部前序 `0.4.3` 提升到 `0.4.4`。

## 测试与验证

发布说明确认重新生成两个 Windows x64 包和 `SHA256SUMS.txt`。历史精确测试总数未保留。当前 `Directory.Build.props` 仍以 `0.4.4`、`0.4.4.0` 作为程序集和文件版本基线。

## 开发状态

状态：**历史正式发布资料存在，当前代码版本基线仍为 0.4.4**。
