## 版本目标

扩展服务与仓库路由模型，支持相互独立的本地/云端 Gitea、多账号 GitHub，以及更精确、可重复应用的 Git URL 重写。

## 计划提交数量

历史资料不足，无法可靠确认。

## 已确认范围

- 新增 Gitea Local 与 Gitea Cloud 服务模板。
- 明确区分登录账号和仓库 Owner。
- 支持 Service、Owner、Repository 三种路由作用域及精确度优先级。
- Gitea 路由覆盖 SCP、`ssh://`、`git+ssh://` 和 HTTPS 来源。
- GitHub 保留多账号 Owner / Repository 选择，不生成覆盖整个服务的默认身份。
- Git 全局 rewrite 改为幂等协调，只处理受管值并保留无关配置。
- 增加遗留路由迁移预览和扩展诊断。
