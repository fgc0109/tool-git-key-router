# GitKeyRouter v0.4.11 开发记录

## 版本目标

防止配置文件或 Git URL rewrite 在加载/预览后被外部修改时，旧操作静默覆盖新状态。

## 实现范围

- 配置快照记录原文件是否存在和原始字节 SHA-256。
- 所有普通配置修改使用条件保存；文件被新建、删除或替换时拒绝覆盖。
- 条件保存返回新版本令牌，事务回滚只在刚写入的配置仍未被第三方修改时执行。
- 每个 Git rewrite 计划记录全部受影响 key 的精确有序值。
- 应用在创建安全快照前和正式写入前两次复核受影响 key。
- 计划外 key 的外部变化不阻断、不写入，也不参与回滚。
- 同时删除旧路由配置的迁移计划携带配置文件令牌，并使用条件保存和条件回滚。

## 测试与失败语义

- 覆盖配置文件从不存在变为存在、已有文件被替换、旧令牌重复使用。
- 覆盖受影响 key 的顺序变化、计划外 key 变化和路由配置陈旧。
- 陈旧状态在任何正式修改前返回失败；配置冲突不会覆盖外部字节。
- 继续验证 Rewrite 部分失败时的自动回滚和计划外 key 保留。
