# GitKeyRouter v0.3.0 开发记录（历史补录）

## 记录性质

本记录依据现有的 [v0.3.0 正式发布说明](../.github/releases/v0.3.0.md) 补录。原始开发计划和精确提交边界未保留，因此不进行推测。

## 版本目标

交付首个面向 Windows 10 / Windows 11 x64 的公开版本，集中管理 Git 服务、SSH 身份、Owner / Namespace 路由、Git Profiles、配置备份和诊断，并同时提供 WinForms 与 CLI。

## 计划提交数量

历史资料不足，无法可靠确认。

## 已确认范围

- 支持 GitHub、GitLab、Gitea 和通用 Git 服务实例。
- 管理多账号 SSH 身份与 GitKeyRouter managed blocks。
- 管理 `url.*.insteadOf` 路由和目录/远程 URL Git Profiles。
- 修改前提供差异和快照，支持选择性恢复。
- 提供自包含与依赖 .NET 8 Desktop Runtime 的两种 Windows x64 单文件构建。
- 发布资产包含两个 ZIP 与 `SHA256SUMS.txt`。
